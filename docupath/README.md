# 📑 DocuPath — Simple, Plain-English Legal & Official Document Generator

DocuPath is a modern, intuitive web application designed to help individuals, freelancers, tenants, and organizations create legally sound, plain-English official documents without needing expensive legal representation.

---

## ✨ Features

- **🎯 Guided Situation Flows**:
  - **Tenant Issues**: Repair requests, deposit refund claims, eviction responses, lease terminations.
  - **Grants & Scholarships**: Arts & cultural grants, academic research, NGO project applications.
  - **Legal Notices**: Recovery of unpaid dues, breach of contract, property possession claims.
  - **Visa & Travel**: Tourist, business, and student visa cover letters.
  - **Small Claims**: Demand letters and pre-litigation notices.
  - **Government Applications**: Permit registrations, welfare scheme applications, record corrections.

- **🌐 27+ Languages Auto-Translation**:
  - Translate the entire application into Hindi, Marathi, Tamil, Telugu, Spanish, French, German, Japanese, Chinese, Arabic, and more with a single click.

- **📍 Jurisdiction Awareness**:
  - Customize documents according to statutory laws and notice periods in India, US, UK, Australia, and Canada.

- **📄 Document Management & Export**:
  - Export generated documents directly as formatted **PDFs**.
  - Edit document text live before downloading.
  - Copy to clipboard with one click.
  - Save documents to your local workspace dashboard (**My Documents**).

- **📅 Deadline Tracking & Reminders**:
  - Automatic calculation of statutory response deadlines.
  - Export deadlines to **Google Calendar** or download **iCal (.ics)** files.

- **🤖 AI Assistant Widget**:
  - Integrated AI assistant to answer questions and direct users to the exact document flow needed.

- **🎨 Modern Responsive Aesthetics**:
  - Dark/Light mode support.
  - Glassmorphism UI elements and responsive mobile navigation.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm` (comes with Node.js)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/docupath.git
   cd docupath/docupath
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Open in Browser**:
   Navigate to `http://localhost:5173/`
